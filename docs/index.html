Mirror trades between MT5 accounts

Tradecopier v2 is a master/slave Expert Advisor pair for MetaTrader 5. One master EA publishes its open positions to a shared file; one slave EA per destination account reads it and mirrors opens, closes, SL/TP changes, and partial closes — with per-account lot sizing and equity protection. A small read-only web dashboard shows live status for everything.

Overview

Why "same-machine" instead of a cloud copier?

Every MT5 terminal installed on a Windows machine shares one Common data folder, independent of the terminal's install path or which account is logged in. That shared folder is the entire transport layer here — no sockets, no DLLs, no firewall rules, no third-party server sitting between your accounts and your orders. Each account (master and every destination) just runs its own separate MT5 terminal install on the same computer.

🔁

Full mirroring

Opens, closes, SL/TP modifications, and proportional partial closes are all mirrored — not just entries and exits.

⚖️

Flexible lot sizing

Fixed lots, a straight multiplier, or scale by the destination account's balance/equity ratio to the master's.

🛡️

Equity protection

Per-slave equity floor and max-drawdown-from-peak halt new copying automatically — no auto-resume, so a breach always gets human attention.

🔀

Symbol mapping & reverse trade

Map broker-specific symbol names, append a suffix, blacklist symbols, or mirror every trade inverted (buy↔sell).

➕

Unlimited destination accounts

Every slave reads the same snapshot independently — scaling out is just installing another terminal.

📊

Live read-only dashboard

Watch every master and slave's balance, equity, open positions, and live P/L from one local web page.

How it works

One shared file, no network calls

The master EA writes a full snapshot of its open positions to the Common folder on a timer, using a write-to-temp-then-rename pattern so a slave never reads a half-written file. Each slave EA polls that same file, diffs it against a ticket map it persists locally, and applies whatever changed since the last cycle.

The master never talks to a slave directly — every slave (and the dashboard) independently reads the same file. Adding a destination account never changes the master's config.

The diff cycle, per slave, each timer tick

  1. Equity protection first

    Runs independent of master data — a frozen or stale master never blocks a halt.

  2. Read the master snapshot

    Missing or unparseable → do nothing this cycle. Stale (older than MaxStaleSeconds on the shared machine clock) → freeze rather than act on old data.

  3. New master position → open it

    Lot size computed per the configured mode, symbol mapped/suffixed, then recorded in the local ticket map.

  4. Known position, volume shrank → partial close

    The proportional fraction is closed on the slave side.

  5. Known position, SL/TP changed → modify

    Swapped automatically if ReverseTrade is on, since direction is inverted.

  6. Mapped ticket vanished from the snapshot → close it

    The master closed it, so the slave closes its mirrored position and drops the mapping.

Running it

cd webapp
pip install -r requirements.txt
python app.py

Then open http://127.0.0.1:8787. If MT5's Common folder isn't at the default Windows location, point the app at it first:

TC_COMMON_FOLDER="C:\Users\you\AppData\Roaming\MetaQuotes\Terminal\Common\Files" python app.py

Installation

One terminal per account

Each destination account needs its own separate MT5 terminal install on this machine — that's what lets each slave have independent lot-sizing and protection settings, and it's what the shared Common folder relies on.

  1. Install a terminal per account

    One MT5 terminal install for the master account, and one more per destination account.

  2. Copy the source files in

    In each terminal, copy MQL5/Include/TC_Common.mqh into that terminal's MQL5/Include/ folder, and the relevant EA (TC_Master.mq5 or TC_Slave.mq5) into MQL5/Experts/. Compile in MetaEditor with F7.

  3. Attach the master

    On the master terminal, attach TC_Master to any chart. Set MasterID to something memorable (defaults to the account login number if left blank). Enable Algo Trading.

  4. Attach each slave

    On every destination terminal, attach TC_Slave to any chart. Set MasterID to the exact same value used on the master. Configure lot sizing, symbol mapping, and equity protection per account. Enable Algo Trading.

  5. Double-check file access

    No DLL imports are needed — this uses only standard file I/O via the FILE_COMMON flag, so just make sure your MT5 install hasn't disabled Common Files access.

Input parameters

Configured per account, via each EA's MT5 inputs

InputMeaning
MasterIDIdentifier slaves use to find this master. Blank = account login number.
UpdateIntervalMsHow often to publish the snapshot.
MagicFilterOnly publish positions with this magic number (0 = all).
InputMeaning
MasterIDMust exactly match the master's MasterID.
PollIntervalMsHow often to check for changes.
MaxStaleSecondsIgnore snapshots older than this (machine clock, not broker server time) — protects against a frozen/crashed master or terminal.
MagicFilterMasterOnly copy master positions with this magic (0 = all).
SymbolBlacklistCSV of master symbol names to never copy.
SymbolMapCSV MASTERSYM:SLAVESYM,... for broker symbol-name differences, e.g. GOLD:XAUUSD.
SlaveSymbolSuffixAppended to the mapped symbol if missing, e.g. .a.
ReverseTradeMirror buys as sells and vice versa (SL/TP swapped accordingly).
LotModeLOT_FIXED, LOT_MULTIPLIER, LOT_BALANCE_RATIO, or LOT_EQUITY_RATIO.
FixedLot / LotMultiplierSizing parameters for the mode above.
SlaveMagicMagic number tagged on every trade this EA opens; also scopes which positions belong to it.
MaxSlippagePointsMax slippage allowed on market execution.
EquityFloorHalt new copying once account equity drops to/below this (0 = disabled).
MaxDrawdownPercentHalt new copying once equity drawdown from this EA's peak reaches this % (0 = disabled).
CloseAllOnEquityBreachIf true, force-close everything tagged with SlaveMagic when equity protection triggers.
Equity protection doesn't auto-resume. Once triggered, the slave EA stops opening new copied trades until it's restarted — a breach always gets human attention rather than silently recovering.
