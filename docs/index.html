Mirror trades between MT5 accounts
on the same machine.

Tradecopier v2 is a master/slave Expert Advisor pair for MetaTrader 5. One master EA publishes its open positions to a shared file; one slave EA per destination account reads it and mirrors opens, closes, SL/TP changes, and partial closes — with per-account lot sizing and equity protection. A small read-only web dashboard shows live status for everything.

Overview

Why "same-machine" instead of a cloud copier?

Every MT5 terminal installed on a Windows machine shares one Common data folder, independent of the terminal's install path or which account is logged in. That shared folder is the entire transport layer here — no sockets, no DLLs, no firewall rules, no third-party server sitting between your accounts and your orders. Each account (master and every destination) just runs its own separate MT5 terminal install on the same computer.

🔁

Full mirroring

Opens, closes, SL/TP modifications, and proportional partial closes are all mirrored — not just entries and exits.

⚖️

Flexible lot sizing

Fixed lots, a straight multiplier, or scale by the destination account's balance/equity ratio to the master's.

🛡️

Equity protection

Per-slave equity floor and max-drawdown-from-peak halt new copying automatically — no auto-resume, so a breach always gets human attention.

🔀

Symbol mapping & reverse trade

Map broker-specific symbol names, append a suffix, blacklist symbols, or mirror every trade inverted (buy↔sell).

➕

Unlimited destination accounts

Every slave reads the same snapshot independently — scaling out is just installing another terminal.

📊

Live read-only dashboard

Watch every master and slave's balance, equity, open positions, and live P/L from one local web page.

How it works

One shared file, no network calls

The master EA writes a full snapshot of its open positions to the Common folder on a timer, using a write-to-temp-then-rename pattern so a slave never reads a half-written file. Each slave EA polls that same file, diffs it against a ticket map it persists locally, and applies whatever changed since the last cycle.

The master never talks to a slave directly — every slave (and the dashboard) independently reads the same file. Adding a destination account never changes the master's config.

The diff cycle, per slave, each timer tick

  1. Equity protection first

    Runs independent of master data — a frozen or stale master never blocks a halt.

  2. Read the master snapshot

    Missing or unparseable → do nothing this cycle. Stale (older than MaxStaleSeconds on the shared machine clock) → freeze rather than act on old data.

  3. New master position → open it

    Lot size computed per the configured mode, symbol mapped/suffixed, then recorded in the local ticket map.

  4. Known position, volume shrank → partial close

    The proportional fraction is closed on the slave side.

  5. Known position, SL/TP changed → modify

    Swapped automatically if ReverseTrade is on, since direction is inverted.

  6. Mapped ticket vanished from the snapshot → close it

    The master closed it, so the slave closes its mirrored position and drops the mapping.

Running it

cd webapp
pip install -r requirements.txt
python app.py

Then open http://127.0.0.1:8787. If MT5's Common folder isn't at the default Windows location, point the app at it first:

TC_COMMON_FOLDER="C:\Users\you\AppData\Roaming\MetaQuotes\Terminal\Common\Files" python app.py

Installation

One terminal per account

Each destination account needs its own separate MT5 terminal install on this machine — that's what lets each slave have independent lot-sizing and protection settings, and it's what the shared Common folder relies on.

  1. Install a terminal per account

    One MT5 terminal install for the master account, and one more per destination account.

  2. Copy the source files in

    In each terminal, copy MQL5/Include/TC_Common.mqh into that terminal's MQL5/Include/ folder, and the relevant EA (TC_Master.mq5 or TC_Slave.mq5) into MQL5/Experts/. Compile in MetaEditor with F7.

  3. Attach the master

    On the master terminal, attach TC_Master to any chart. Set MasterID to something memorable (defaults to the account login number if left blank). Enable Algo Trading.

  4. Attach each slave

    On every destination terminal, attach TC_Slave to any chart. Set MasterID to the exact same value used on the master. Configure lot sizing, symbol mapping, and equity protection per account. Enable Algo Trading.

  5. Double-check file access

    No DLL imports are needed — this uses only standard file I/O via the FILE_COMMON flag, so just make sure your MT5 install hasn't disabled Common Files access.

Input parameters

Configured per account, via each EA's MT5 inputs

Every setting below, in plain English, with the exact input name you'll see in MT5 shown alongside it. One thing worth knowing: MT5's Inputs dialog shows each input's description as the row label instead of its actual name, whenever that input has one — so if a row looks unfamiliar, widen the "Variable" column (or the whole window) and match its full description text against the explanations below.

Publishing

MasterIDdefault: blank

The name other accounts use to find this master. Leave it blank and it defaults to this account's own login number — simplest option is to leave it blank here and just tell every slave that login number.

UpdateIntervalMsdefault: 250

How often (in milliseconds) this account publishes its current positions for slaves to pick up. 250ms means it publishes 4 times a second.

MagicFilterdefault: 0 (all)

Only publish positions tagged with this exact magic number. Leave at 0 to publish everything open on this account, no matter what opened it.

Which master to follow

MasterIDdefault: blank

Must exactly match the value set on the master (or its login number, if the master left MasterID blank). This is how a slave finds the right snapshot file — get it wrong and this account simply never sees any master data.

PollIntervalMsdefault: 250

How often this account checks the master's file for changes. 250ms means 4 checks a second.

MaxStaleSecondsdefault: 5

Safety check: if the master hasn't updated its file in this many seconds, treat it as offline and freeze — no opens, closes, or modifies — rather than act on information that might be out of date. Protects against a frozen or crashed master terminal.

MagicFilterMasterdefault: 0 (all)

Only copy master positions tagged with this exact magic number. Leave at 0 to copy everything the master has open.

Which trades get copied, and onto what symbol

SymbolBlacklistdefault: blank

Symbols to never copy, no matter what. Comma-separated, e.g. US30,XAUUSD — if the master opens either of those, this account ignores it completely.

SymbolMapdefault: blank

Renames a symbol when your two brokers call the same instrument something different. Example: master's broker calls gold GOLD, yours calls it XAUUSD → set GOLD:XAUUSD. You can map several, separated by commas: GOLD:XAUUSD,OIL:USOUSD.

SlaveSymbolSuffixdefault: blank

Appended automatically to the (possibly renamed) symbol if it isn't already there — for brokers that tag every symbol, e.g. EURUSD.a instead of EURUSD. Set this to .a and it's added wherever needed, without you having to bake it into every SymbolMap entry.

ReverseTradedefault: false

Turn this on to mirror the opposite direction: every master BUY opens as a SELL here, and vice versa. The stop-loss/take-profit levels are swapped automatically so they still make sense for the reversed trade — a stop-loss only means something relative to a trade's direction, so once the direction flips, the master's stop-loss level becomes the correct take-profit for this account (and vice versa). You don't need to configure anything extra for that swap.

How big each copied trade is

LotModedefault: LOT_MULTIPLIER

Which formula decides the lot size of every trade this account opens:

  • LOT_FIXED — always trades FixedLot lots, ignoring the master's volume entirely.
  • LOT_MULTIPLIER — masterVolume × LotMultiplier. E.g. master trades 1.00 lots, LotMultiplier = 0.5 → this account trades 0.50 lots.
  • LOT_BALANCE_RATIO — scales by this account's balance versus the master's. E.g. this account's balance is half the master's → it automatically trades half the lots.
  • LOT_EQUITY_RATIO — same idea as above, but using equity instead of balance.
FixedLotdefault: 0.01

The lot size used for every trade when LotMode = LOT_FIXED.

LotMultiplierdefault: 1.0

The multiplier used by LOT_MULTIPLIER, LOT_BALANCE_RATIO, and LOT_EQUITY_RATIO (see above).

Identifying this account's own trades

SlaveMagicdefault: 990001

The magic number tagged on every trade this EA opens, so it can tell "its own" trades apart from manual trades or other EAs on this account. Also used to decide which positions get swept during equity protection / force-closes.

MaxSlippagePointsdefault: 30

Maximum price slippage (in points) allowed when placing a market order. If the price has moved further than this by the time the order reaches the broker, it's rejected instead of being filled at a worse price.

Risk & safety limits

EquityFloordefault: 0 (disabled)

A hard equity number. Set it to 9000 and new copying halts the moment equity hits £9,000 or below.

MaxDrawdownPercentdefault: 0 (disabled)

A % drop from the highest equity this EA has seen since it started. Example: equity peaks at £11,000, set this to 10 → halts if equity then falls to £9,900 or below (10% down from that peak). This and EquityFloor trigger independently — you don't need both; set whichever one you don't want to 0.

Once either one triggers, new copied trades stop opening (existing ones still get closed/modified as normal) until you restart the EA — it does not resume on its own.

CloseAllOnEquityBreachdefault: false

When either equity halt above triggers, turning this on also force-closes every position this EA has open immediately, instead of just freezing new copying and leaving existing positions running.

DailyLossLimitPercentdefault: 0 (disabled)

A separate, simpler rule: "don't lose more than X% today." Set it to 3 and if equity ever falls 3% below wherever it was when this EA first saw today, everything gets force-closed for the rest of the day.

Unlike EquityFloor/MaxDrawdownPercent above, this one resumes on its own the next broker day, using that new day's equity as the fresh starting point — no restart needed. One caveat: if you restart the EA partway through a day, that moment's equity becomes the new "start of day" reference, not midnight's true value.

MaxTotalRiskPercentdefault: 0 (disabled)

Caps how much you could lose across everything currently open at once — not equity after the fact, but risk before it happens. For every open position it works out "if this position's stop-loss got hit right now, how much would that lose," and adds those up across all of them.

Set this to 2 and a new trade only opens if doing so keeps that running total at or under 2% of equity — otherwise the trade is skipped entirely for that cycle (not opened smaller, just not opened; it's retried again next cycle in case equity or open risk has since changed). Any master position with no stop-loss is always skipped under this rule, since there'd be no way to know how much it could lose.
